**Output_ChannelSelect**<br>

- Description: *This Plugin controls the routing of an audio bus to a specific channel of a main audio bus or the configured device. You can use this plugin to connect the outputs of each audio bus to separate channels in Reaper with Rearoute using the AK ASIO plugin in the device.*
- Instalation: *Add the .ZIP to the Wwise Launcher in Plug-ins section for the Wwise version soported*
- Platform Soported: Windows
- Download: [Compatible Wwise version](https://github.com/Dantepog/Dantepog_WwiseScripts/releases/tag/Plugins)
